# Security Policy

FlowPulse is pre-audit software deployed **only on Stellar testnet**. Do not use it with real funds.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **"Report a vulnerability"** button (Security → Advisories) on this repository. Do not open a public issue.

Include the affected contract/function or file, reproduction steps (a failing `cargo test` is ideal), and the impact. We aim to acknowledge reports within 72 hours.
